Browse like a Mac, work like a pro

Everything you wished File Explorer had.

Four ways to browse, instant previews, real search and a keyboard for everything, in a small native app that starts in a blink.

Column view, finally on Windows.

See every level of your folders side by side, with a live preview of the selected file. Move with the arrow keys, and the path is always in view.

  • Finder-style columns with a preview of photos, documents and code
  • List, icon and gallery views too, remembered per folder
  • Folders that show what's inside them

Press Space. See anything.

Quick Look opens any file instantly, and the arrow keys flick to the next one. The preview pane keeps it on screen while you browse.

  • Images, PDF page by page, Word, PowerPoint, Excel and CSV
  • Markdown, text and logs, and source code in colour
  • Video and audio play right inside Quick Look

Find files by what's inside them.

The search box covers the folder and every subfolder as you type. Add filters, or search the text inside your documents.

  • content:"invoice 2026" searches inside PDF, Word, PowerPoint, Excel and text files
  • Filters like pdf: kind:image size:>5mb modified:week
  • Type a name to jump to it; press the letter again to cycle through matches

See where your space went.

Turn on folder sizes and every folder shows its real size with a bar, so you can sort by size and find what's filling your disk in seconds.

  • Sizes for every folder, calculated in the background
  • Percentage bars to compare folders at a glance

Split panes

Two side by side, stacked, one plus two, or a grid of four. Each pane is a tab.

Tabs and tab groups

Save a set of tabs as a group and reopen it with one click or a shortcut.

Colour tags

Tag files and folders; tagged folders take the colour and tags travel with the file.

Your own shortcuts

Give any action the key you like, plus one key that opens X Finder from anywhere, instantly.

Made for developers

Syntax-highlighted previews, Open in VS Code, and run git or any command from the palette.

Light and dark

Follows Windows or your choice, with crisp, carefully tuned text in dark mode.

Drag into any app

Drag files to Telegram, browsers, the desktop or Explorer, just like Windows does.

Undo with Ctrl+Z

Copied, moved, renamed or deleted the wrong thing? Ctrl+Z puts it back, step by step.

Drag to select

Draw a box over files to select them, and Alt+Enter shows one Properties window for all of them.

Chain commands

select *.pdf; move to PDFs in one line. ↑ brings back earlier commands.

Find recent files

Type part of a name in the palette to reopen any file you used before, even ones opened from other apps.

Batch rename

rename *.jpg trip-{n}.jpg with a live preview before anything changes.

Optional: folders, shortcuts and "Show in folder" from other apps open in X Finder (and Win+E on Windows 10).

Questions

Frequently asked questions

Is X Finder free?

Yes. X Finder is free and open source under the GNU GPL v3. There are no ads, accounts or subscriptions.

Does it work on Windows 11 and Windows 10?

Yes. X Finder runs on 64-bit Windows 10 and Windows 11. It's a single .exe with nothing to install: unzip it and run it. Because the app isn't code-signed yet, Windows may say "Windows protected your PC" the first time. Click More info → Run anyway.

Can X Finder replace File Explorer?

Yes. Turn on Settings → Use as the default file explorer, and folders, shortcuts and "Show in folder" from other apps open in X Finder. You can switch back to Windows File Explorer at any time.

Does it have a column view like the Mac Finder?

Yes. Column view shows every level of the folder path side by side with a live preview of the selected file, just like the macOS Finder. There are list, icon and gallery views too.

Can I preview files without opening them?

Yes. Press Space for Quick Look, or keep the preview pane open. X Finder previews images, PDFs, Word, PowerPoint, Excel, CSV, Markdown, text and source code, and plays video and audio.

Can it search inside files?

Yes. Type content:"words" in the search box to find files by the text inside them, including PDF, Word, PowerPoint, Excel and text files. Searches cover all subfolders and update as you type.

Is it fast on big folders?

Yes. X Finder lists 100,000 files in about a fifth of a second on a background thread and stays smooth while you scroll. It uses around 35 MB of memory, because there's no browser engine inside.
